Kids dua bundled audio should live in this folder.

Canonical path:
- `assets/audio/kids_dua/en/path_of_nur/`

Recommended filename convention:
- `<dua_id>_kids_dua_en_v1.mp3`

Examples:
- `before_sleep_kids_dua_en_v1.mp3`
- `before_eating_kids_dua_en_v1.mp3`
- `after_waking_up_kids_dua_en_v1.mp3`

Notes:
- The app resolves bundled dua audio from this canonical directory first.
- If a file is missing, the dua learning page falls back to readable content and tap-to-repeat text mode without exposing a broken play state.
- Segment-level tap-repeat currently falls back to whole-dua playback until dedicated segment assets or timing offsets are authored.
