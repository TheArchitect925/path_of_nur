# Quran Summary Phase 4 Enhancement Backlog

Date: 2026-03-31

## High-signal next enhancements

1. Add scholar-review metadata per enrichment entry.
   Keep the current internal evidence levels, then add optional review fields such as reviewer name, review date, and review status without surfacing noisy editorial chrome in the UI.

2. Expand curated enrichment coverage across all 114 surahs.
   Phase 4 introduces the scalable system and a meaningful curated starter set, but many surahs still rely mainly on concise overview plus inferred themes.

3. Localize the editorial enrichment corpus.
   Section titles and theme labels are localized now, but the longer seeded enrichment bodies still need multilingual translation planning and review.

4. Add thematic discovery on top of normalized theme tags.
   The data layer now supports future browsing like patience, tawhid, Musa, or judgment without needing a new content model.

5. Add prophet and event deep links.
   The related-prophet and related-event chips are ready for future navigation into Prophets, Seerah, History, or Learn companion surfaces.

6. Add scholar-safe virtue review gates.
   Consider a stricter rule where devotional or recitation-association notes require explicit internal review before they become user-visible in broader coverage.

7. Reuse the enrichment system in other Qur'an surfaces.
   Surah Insights, Daily Companion, and future reflection pages can reuse the same notable-ayah, theme, and reflection structures instead of creating parallel content seeds.

8. Add widget coverage for enriched detail sections.
   Good targets: notable ayat rendering, hidden empty sections, reader action visibility, and mixed enrichment combinations in light/dark modes.

9. Add per-surah content-source notes for internal editorial workflows.
   This can stay internal-only and support future scholar review without cluttering the product UI.

10. Add a gentle save/reflection CTA from the enriched detail page.
    This would connect Surah Summary Detail more directly to the existing private Saved Reflections flow once the product intent is confirmed.
