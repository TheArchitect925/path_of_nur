# Game Variations System Backlog

Date: 2026-03-21

## Recommended enhancements

1. Add pack-level variation surfacing so featured packs can intentionally advertise supported modes instead of only daily assignments.
2. Extend variation-aware widget tests for timer rendering, hint-disabled states, reverse matching layout, and sequential gating.
3. Add richer Word Search fog treatment that affects grid visibility instead of only the support list.
4. Add a shared post-completion handoff so variation bonuses can be surfaced more explicitly on completion cards.
5. Add per-game validation for unsupported variation combinations at repository/build time, not only engine-level config validation.
6. Let adaptive learning introduce or suppress specific variation families over longer windows instead of only day-level comfort checks.
7. Connect Spiritual Growth summaries to calm variation use cases such as reflection mode or challenge-with-intention runs.
