# Quran Reader Scroll Smoothness Follow-ups

Date: 2026-04-10

## Safe enhancement options
- Run a real-device QA pass comparing route entry, search-result entry, and in-reader whole-Qur'an result entry for perceived smoothness on longer surahs.
- If deeper ayah jumps still feel abrupt on very long surahs, consider one tiny eased fade/highlight cue on the target ayah rather than adding more scroll animation passes.
- If future late-loading verse decorations still cause visual nudge, consider freezing optional below-ayah sections until after the first exact landing completes.
