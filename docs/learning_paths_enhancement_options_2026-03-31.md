# Guided Learning Paths Enhancement Options

Date: 2026-03-31

## Option 1 — Adaptive path recommendations

- Recommend a starter path based on profile mode, recent activity, and unfinished Learn surfaces.
- Keep recommendations advisory rather than mandatory.

## Option 2 — Seasonal guided paths

- Add Ramadan, Dhul Hijjah, Friday, and back-to-basics seasonal paths.
- Reuse existing worship, dua, and Qur'an owners instead of creating seasonal duplicate content.

## Option 3 — Better completion automation

- Auto-complete steps when a destination already emits a safe completion event.
- Reduce manual "Mark complete" usage over time without adding fragile detection.

## Option 4 — Searchable path metadata

- Expose path titles, subtitles, tags, and step summaries through the shared Learn search system when product wants paths to be discoverable outside `/learn`.

## Option 5 — Richer rewards and milestone states

- Add a modest path-complete celebration or badge state using existing XP/Ocean conventions.
- Keep the reward balance conservative and non-exploitable.

## Option 6 — Family-aware guided starts

- Recommend the Kids Starter Path or a general starter path automatically depending on the active profile context.
- Keep all route ownership and audience safeguards intact.
