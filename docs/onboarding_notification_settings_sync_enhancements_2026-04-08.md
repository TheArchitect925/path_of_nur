# Onboarding Notification Settings Sync Enhancements

Date: 2026-04-08

## Ideas

- Consider auto-enabling the master `Prayer reminders` toggle in Settings when a user switches any individual prayer from `Off` to another mode there.
- Add a tiny derived status line in Settings later, such as `All off`, `Some on`, or `All on`, so the master reminder state is easier to understand at a glance.
- Add a focused regression test for onboarding reminder choices to verify the master profile reminder flag and per-prayer modes stay synchronized.
