# Onboarding Tracking Page Hide Enhancements

- When the tracking preference feature is ready, bring the page back only after its choices clearly affect Home, Learn, or reminder personalization in a visible way.
- Consider reintroducing it later as an optional advanced setup screen or a settings-only surface rather than a required onboarding stop.
- If the dormant tracking module state remains unused for long, audit whether those saved fields should be retired or migrated into a more purposeful personalization model.
