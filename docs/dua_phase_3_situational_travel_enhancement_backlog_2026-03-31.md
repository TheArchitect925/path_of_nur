# Dua Phase 3 Enhancement Backlog

Date: 2026-03-31

## Potential enhancements

- Add a lightweight `sourceNotes` field or authoring comment path for entries like `Thunder` where the text is an authenticated companion athar rather than a marfu` hadith.
- Add product-facing badges or filters that distinguish:
  - Qur'anic duas
  - Prophetic duas
  - companion-practice adhkar
- Add a small in-app note for dual-purpose protection entries so users can understand the difference between:
  - ruqyah against envy and evil eye
  - asking for barakah when admiring something
- Run a transliteration normalization pass for long entries so apostrophes, long vowels, and line breaks are fully consistent across all completed duas.
- Add a validation check that flags potentially overlapping titles across categories before future stub batches are filled.
- Consider adding a future `healing` filter tag surface in the Dua hub once family and forgiveness phases are complete, since illness-related duas are now a meaningful sub-collection.

## Risks to review later

- `Entering a Marketplace` is included because it appears in Hisn al-Muslim and is graded good there, but it is worth flagging for final scholarly QA because it is commonly discussed in grading conversations.
- `Thunder` should remain documented as an athar from Ibn al-Zubayr rather than presented as a direct prophetic hadith.
- `Repentance and Seeking Forgiveness` in the situational section should be checked against the future forgiveness phase to avoid user-facing duplication with the fuller `Sayyid al-Istighfar` entries.
