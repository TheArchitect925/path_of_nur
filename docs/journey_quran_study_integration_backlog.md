# Journey Qur'an Study Integration Backlog

## Highest-value next steps

1. Expand contextual Journey → Qur'an mappings only for lessons with strong, explicit Qur'anic anchors instead of applying the pattern broadly.
2. Add a dedicated context-aware Surah Insights handoff for stage types that are more surah-shaped than ayah-shaped, such as Yusuf or Al-Kahf journeys if those become real lesson owners.
3. Add richer localized relation-reason copy for the strongest Qur'an → Journey links so the detail sheet can name the exact lesson connection instead of using the generic journey fallback.
4. Review whether the Journey context banner should optionally show a lightweight “continue this lesson” state after returning from the reader.
5. Audit contextual entry opportunities from Daily Wisdom and companion surfaces into the same Journey-aware Qur'an reader query pattern.

## Enhancement options

1. Add a small shared resolver that can choose between reader entry, surah insights, and thematic-map entry when a Journey lesson is clearly verse-first, surah-first, or theme-first.
2. Let the Qur'an reader preselect a matching Ayah Insights domain when a Journey context carries a strong theme but no explicit thematic topic ID.
3. Add one calm “study next in Journey” block to high-value Surah Insights pages if future Qur'an → Journey mapping grows beyond the first curated set.
4. Expand integration tests to cover specific contextual lesson buttons on the Journey lesson page after the current route-safe slice has settled.
